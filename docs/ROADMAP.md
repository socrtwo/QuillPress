# Roadmap

- **M1:** shell, reading view, page navigation, search, annotations, basic edit and export.
- **M2:** forms, signatures, organize pages, OCR, compare, accessibility and preflight.
- **M3:** repair engine, damaged PDF recovery, portfolio support, batch tools.
- **M4:** AI tab, review workflows, document cloud connectors, mobile builds.
- **M5:** historical-format support, advanced prepress tools, polish.
