# Innovations survey

Ideas QuillFolio plans to adopt, described generically.

| Origin | Ideas adopted |
|---|---|
| Acrobat and current PDF editors | Annotate, redact, sign, compare, fill forms, OCR, preflight, linearize, accessibility check, Bates numbering, portfolio support |
| Preview, Okular, Sumatra, PDF-XChange, Foxit, Nitro | Fast viewing, tabs, search, comments, measurement, multiple documents, form fill, stamp tools |
| PDFsam, qpdf, pdftk, Ghostscript | Split, merge, extract, rotate, optimize, repair, page-level manipulation, command-line compatibility |
| Bluebeam | Review workflows, markup sets, estimates and measurements |
| Document cloud tools | Share links, review sessions, history and permissions |
| Office/PDF bridges | Export from Office-like apps, import scanned docs and office-generated PDFs |

Original ideas: repair diff with a side-by-side recovered-object map, an accessibility-first assistant, redaction audit trails, compare-as-you-type, live form helper, page rotation inference, and a document similarity index.
