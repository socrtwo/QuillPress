# Command plan (by tab)

Every command has an id, label, icon, tab and group (or *not in tabs*).

- **File:** New, Open, Close, Save, Save As, Create Portfolio, Import, Export, Print, Properties, Recover Damaged File.
- **Home:** Select, Hand, Zoom, Clipboard, Find, Search, Undo/Redo.
- **Edit:** Copy, Paste, Cut, Delete, Insert, Duplicate, Rotate, Crop, Snapshot, OCR cleanup.
- **View:** Page, Facing, Continuous, Presentation, Read mode, Show/Hide panels, Rulers, Grid, Zoom, Rotate view.
- **Comment:** Highlight, Underline, Strikeout, Note, Text box, Drawing, Stamp, Attach file, Audio comment, Measurement, Compare.
- **Forms:** Text field, Check box, Radio button, Combo box, List box, Button, Signature field, Calculate, Validate, Reset, Extract data.
- **Protect:** Encrypt, Permissions, Redact, Sanitize, Remove hidden data, Audit trail.
- **Sign:** Fill and sign, Sign with certificate, Request signatures, Timestamp.
- **Organize Pages:** Insert, Delete, Replace, Extract, Split, Merge, Rearrange, Rotate, Crop, Split document.
- **Scan/OCR:** Scan, Recognize text, Deskew, Denoise, Reorder pages.
- **Review/AI:** Summarize, explain, translate, alt text, redaction suggestions, accessibility repair, ensemble.
- **Help.**

The id-level inventory will be generated into docs/COMMANDS.md when code exists.
